# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep criticism about the work, not the person. Harassment, insults and personal attacks aren't acceptable in issues, pull requests or anywhere else connected to the project.

If something goes wrong, contact me through my GitHub profile ([@adityarajsingh1](https://github.com/adityarajsingh1)). Reports are kept confidential.
